# Named Entity Recognition (NER) System

A complete, locally-run college project that identifies **PER** (person), **ORG**
(organisation), **LOC** (location), **MISC** (miscellaneous) and **DATE** named
entities in user text, with a Streamlit graphical user interface.

The NER model is fine-tuned from **DistilBERT** (configurable to BERT) on the
**CoNLL-2003** dataset using Hugging Face `transformers` and the PyTorch **MPS**
backend (Apple Silicon). Because CoNLL-2003 has no DATE label, DATE entities are
detected with **spaCy** (`en_core_web_sm`) and merged with the model output
without overlapping spans.

## Project goal

Given any free-text input, extract named entities and present them:
- highlighted inline in the text (colour-coded by entity type)
- in a pandas table (Entity | Label | Confidence)
- with per-category counts and a CSV download option

## Environment constraints

- Developed on an Apple Silicon Mac (M5 base, macOS) with the PyTorch **MPS** backend
- Also runs on **Windows / Linux on CPU** (tested on Windows 11, Python 3.13).
  Full training on CPU takes roughly an hour; a smoke run takes a few minutes.
- **No fp16/bf16 flags**, **no paid APIs**, **no API keys** —
  everything runs locally and free
- On Mac, before training: `export PYTORCH_ENABLE_MPS_FALLBACK=1`
- Python 3.11/3.12 (tested on 3.13 and 3.14) with a dedicated venv

## Setup

```bash
# 1. Create the project folder and virtual environment
mkdir -p ~/ner_project && cd ~/ner_project
python3 -m venv venv

# 2. Activate the venv and set the MPS fallback flag
source venv/bin/activate
export PYTORCH_ENABLE_MPS_FALLBACK=1

# 3. Install dependencies
pip install -r requirements.txt

# 4. Download the spaCy English model
python -m spacy download en_core_web_sm

# 5. Verify MPS is available
python -c "import torch; print(torch.backends.mps.is_available())"
```

### Setup on Windows (PowerShell)

```powershell
git clone https://github.com/lakshyadangwal/ner-system
cd ner-system
python -m venv venv
.\venv\Scripts\Activate.ps1

# CPU build of PyTorch (smaller download), then the rest

```

If PowerShell blocks `Activate.ps1`, you can skip activation and call
`.\venv\Scripts\python.exe` directly instead of `python`.

## How to train

```bash
# Quick smoke test (500 train / 200 val samples, 1 epoch) — verifies everything works
python train.py --smoke

# Full training (3 epochs, all ~14k train samples). Runs in the background,
# logs to training.log, saves the model to ./model and metrics to metrics.json.
nohup python train.py > training.log 2>&1 &
```

Expected full-training result (DistilBERT): test F1 ≈ 0.88–0.92. BERT is
slightly higher but slower. Switch models with `--model-name bert-base-cased`.

Note: the smoke run only checks that the pipeline works. Its model is not
usable (F1 is close to 0) and the app shows a warning when it is loaded.
On Windows, run full training with `python train.py > training.log 2>&1`
(no `nohup`).

## How to run the tests

```bash
python -m unittest discover tests -v
```

The helper tests run without a model. The end-to-end tests need a fully
trained model in `./model` and are skipped if it is missing.

## How to run the app

```bash
source venv/bin/activate
export PYTORCH_ENABLE_MPS_FALLBACK=1
streamlit run app.py --server.headless true
```

Then open http://localhost:8501 in your browser. Paste text, click **Extract
Entities**, and view the colour-coded highlights, entity table and counts.

## How CoNLL-2003's missing DATE label is handled

CoNLL-2003 only defines PER, ORG, LOC and MISC. The fine-tuned model therefore
never predicts DATE. `ner_engine.py` loads spaCy's `en_core_web_sm`, extracts
DATE entities, and merges them with the model entities so that:
- model entities take priority on overlap (a DATE overlapping a PER/ORG/LOC/MISC
  span is dropped),
- the final list is sorted by character start position,
- DATE entries get a score of 1.0 (rule-based, from spaCy).

## Limitations

- Trained only on CoNLL-2003 (English newswire); performance may drop on other
  domains (social media, scientific text, etc.).
- DATE detection depends on spaCy's rule-based NER and covers common date
  formats only.
- MPS backend can occasionally fall back to CPU for some ops
  (`PYTORCH_ENABLE_MPS_FALLBACK=1` handles this).
- Single-threaded Streamlit app; one user at a time in this simple deployment.
